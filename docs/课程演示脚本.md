# 课程演示脚本

建议准备两个浏览器或一个普通窗口加一个无痕窗口，分别登录组长和组员账号。

1. 组长创建课程小组并生成邀请码；组员通过邀请码加入。
2. 组长为组员授予任务发布或成员管理权限，现场展示有权限与无权限操作的差异。
3. 组长发布带截止时间的任务，组员开始任务、选择资料库附件并提交成果。
4. 组长先退回一次，组员提交第二版，组长审核通过；展开任务可查看全部历史版本。
5. 在共享资料库查看自动标记的“任务成果”，演示预览、分类、容量、回收站和“下载已验收成果”。
6. 发布小组讨论、置顶公告和任务留言，查看另一账号收到的站内通知。
7. 上传临时中转文件，使用无痕窗口扫描或打开取件链接；再演示“保存到我的设备”和“导入当前小组”。
8. 切换两个小组，展示个人工作台跨组汇总和统一搜索的所属小组标识。
9. 打开“操作记录”，说明关键写操作可追溯；展示成员离组再加入后不会自动恢复旧任务权限。
10. 最后打开 AI 协作助手预留页，说明当前开关关闭，下一阶段才通过 DeepSeek 接入，AI 故障不会影响已有功能。

答辩前应重新执行后端测试和前端构建，并从空数据库完成一次 Docker 部署与备份恢复演练。
