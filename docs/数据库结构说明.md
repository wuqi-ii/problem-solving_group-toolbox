# 数据库结构说明

数据库由 Flyway 管理，当前版本为 V8。开发测试使用 H2 的 MySQL 兼容模式，部署配置使用 MySQL 8.4 和 `utf8mb4`。

| 迁移 | 核心内容 |
| --- | --- |
| V1 | 用户、小组、成员关系、权限授权、基础文件对象 |
| V2 | 小组邀请码、有效期、次数与撤销状态 |
| V3 | 任务、当前/历史执行人、成果提交版本、审核记录与通知 |
| V4 | 小组共享文件元数据和受控物理存储引用 |
| V5 | 临时中转、匿名取件和个人跨设备空间 |
| V6 | 小组讨论、任务留言和公告 |
| V7 | 文件分类、版本号、回收站时间和容量索引 |
| V8 | 用户写操作审计日志 |

主要关系为：用户与小组通过成员表形成多对多；小组包含任务、协作内容和共享文件；任务包含多名执行人和多个提交版本；提交可引用同组共享文件；临时中转和个人设备空间归属于创建用户，但匿名取件只通过不可预测的取件码访问。

数据库只保存文件元数据与物理存储键，文件正文位于 `STORAGE_LOCATION`。备份和恢复必须在同一时间点同时处理数据库与文件目录，否则可能产生失效引用。部署目录中的脚本已经按这一原则同时处理两部分。
