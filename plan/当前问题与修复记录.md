# 当前问题与修复记录

更新日期：2026-10-12

本文从用户使用和需求一致性角度记录第二轮检查结果。AI 功能仍安排在非 AI 功能验收完成后接入，本轮没有配置 DeepSeek 密钥，也没有启用外部模型调用。

## 本轮已修复

| 问题 | 修复结果 | 验收方式 |
| --- | --- | --- |
| 手机端隐藏侧边栏后没有导航 | 增加移动端抽屉菜单，核心模块均可进入 | 680px 以下页面检查 |
| 各模块各自选择第一个小组 | 当前小组写入 Pinia 和本地存储，由顶部选择器统一切换 | 工作台、任务、资料库连续切换 |
| 工作台只有静态说明 | 接入任务、个人待办、待审核、文件数、未读通知和最近任务 | 使用真实小组数据检查统计与跳转 |
| 普通成员看得到发布任务但点击后报权限错误 | 根据组长身份或 `TASK_CREATE` 权限显示发布入口 | 普通成员与授权成员分别登录 |
| `MEMBER_MANAGE` 被授予后实际不能管理成员 | 允许管理邀请码和移除普通成员，同时保留授权与组长转让的组长专属边界 | 接口测试与不同角色页面检查 |
| 取消任务会清除执行人 | 取消只终止任务状态并发送通知，保留执行人用于历史追溯 | 取消接口断言执行人仍存在 |
| 页面只显示最新成果版本 | 任务卡片支持展开全部提交版本及其审核结果、附件 | 两次提交一次退回场景检查 |
| 删除资料库文件会导致历史任务附件失效 | 被任务成果引用的文件禁止删除并给出明确提示 | 引用后删除返回 409 |
| 下载次数耗尽的中转文件未进入清理 | 定时清理同时处理过期和次数耗尽记录 | 服务层状态与存储清理检查 |
| 缺少讨论、公告和任务内沟通 | 增加小组讨论、权限公告、置顶、任务留言、软删除和相关通知 | V6 迁移、接口测试与页面检查 |
| 任务变化和截止时间缺少提醒 | 增加修改通知、截止前 24 小时提醒和逾期提醒 | 通知列表与提醒服务测试 |
| 多人任务完成含义不明确 | 固化为共同完成模式，任一执行人提交后整体进入审核 | 创建任务提示与状态流转测试 |
| 离组成员可能因历史任务关系继续收到通知 | 留言和截止提醒发送前重新校验有效组员身份 | 离组权限边界检查 |
| 重新加入后可能重新获得旧任务执行权 | 离组时将指派转为历史，重新加入不自动激活；页面区分当前与历史执行人 | 移除、重新加入与任务接口测试 |
| 中转、个人设备和资料库互不衔接 | 支持取件保存到跨设备空间、设备文件复制到小组资料库，再用于任务提交 | 工具流转端到端测试 |
| 文件管理缺少分类、预览和恢复 | 增加分类、版本、容量、基础预览、回收站、恢复和彻底删除 | V7 迁移与接口测试 |
| 已验收成果仍需手工整理 | 审核通过自动标记任务成果，并可下载已验收成果 ZIP | 审核与归档测试 |
| 工作台只关注一个小组 | 聚合全部有权小组，并提供统一搜索和小组定位 | 前端生产构建与页面检查 |
| 关键操作无法追溯 | 增加 V8 审计日志、自动记录过滤器和个人操作记录页 | 审计接口测试 |
| 匿名取件易被频繁探测 | 增加按 IP 分钟限流、二维码和可复制取件链接 | 二维码接口测试 |
| 缺少可重复部署和联合备份 | 增加 MySQL/Nginx/Docker Compose、健康检查、数据库与文件联合备份恢复脚本 | 配置审查与目标环境清单 |
| 文件预览点击后没有反应 | 改为当前页面内嵌文本、图片和 PDF 预览，不依赖异步 `window.open` | 真实演示文件预览及 390px 截图 |
| 代理后匿名取件用户共用限流额度 | 统一解析可信代理地址，并按“客户端地址 + 取件码”隔离计数 | 新增限流过滤器自动化测试 |
| 手机任务和资料库横向溢出 | 任务长内容允许换行，资料库窄屏使用文件卡片 | CDP 390×844 复测，页面宽度与滚动宽度均为 390 |
| 前后端未知地址反馈错误 | 后端未知 API 返回规范 404；前端增加 404 页面及返回入口 | 接口测试、真实部署请求和移动端截图 |
| 页面加载闪烁错误空状态 | 增加页面初始化骨架状态 | 刷新任务与资料库页面检查 |
| 输入框缺少可访问名称 | 为搜索、筛选、讨论和取件等控件补充标签 | 无障碍属性检查 |
| 审计记录技术信息难读 | 显示可读业务对象名称，并区分代理/内网地址 | 审计页面检查 |
| 静态资源体积与传输效率不足 | 路由与依赖拆包，Nginx 启用 gzip、哈希缓存和安全响应头 | 构建产物、响应头和 `nginx -t` 检查 |
| 登录注册没有独立限流 | 增加按客户端地址和认证端点隔离的分钟限流 | 自动化限流测试 |
| 前端异常处理重复且使用 `any` | 增加统一 API 错误解析和取消判断工具 | TypeScript 生产构建 |

## 仍需开发

核心业务代码仅剩 DeepSeek Agent：模型适配、会话与计划、工具确认、隐私授权、聊天总结、资料问答、调用用量和 Agent 专项审计。完整 Docker/MySQL 启动已经验证；联合备份的隔离恢复演练、HTTPS 和 Element Plus 按需引入属于部署或性能优化，不阻塞课程演示。

## 当前验收结论

- 后端自动化测试共 9 个，失败 0、错误 0；新增认证限流、取件码限流隔离和未知接口 404 回归。
- 前端生产构建通过；应用入口、Vue 和 HTTP 依赖已拆分，Element Plus 依赖包仍有体积警告，但 Nginx gzip 与长期缓存已生效。
- 390×844 下任务页、资料库、文件预览和 404 页面均通过，未出现页面级横向滚动。
- 非 AI 版本达到课程项目交付基线；Docker、MySQL 8.4、真实迁移、全容器构建以及经 Nginx 的主流程均已验证。
